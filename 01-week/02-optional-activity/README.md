## 3. Expectativas del curso

Durante el curso de Inteligencia de Negocios espero aprender a transformar datos en información útil para apoyar la toma de decisiones. También quiero aprender a utilizar herramientas como Power BI para construir dashboards que permitan visualizar indicadores de una manera clara y comprensible. Como estudiante de Ingeniería de Sistemas, considero importante comprender cómo se pueden integrar datos provenientes de diferentes fuentes y convertirlos en conocimiento. Me gustaría aprender conceptos relacionados con bases de datos analíticas, procesos ETL, Data Warehouse y modelos dimensionales. Un problema de mi entorno que me gustaría analizar es el rendimiento académico de los estudiantes universitarios, identificando tendencias como materias con mayor pérdida, cantidad de estudiantes matriculados y comportamiento de las calificaciones. Finalmente, espero poder desarrollar dashboards que permitan analizar estos datos de forma interactiva y facilitar la identificación de situaciones que requieran atención.

---

## 4. Fuente de los datos

Para analizar el rendimiento académico podrían utilizarse datos provenientes del **sistema académico de la universidad**.

Una fuente real o plausible podría contener información como:

* Código del estudiante.
* Programa académico.
* Semestre.
* Materia.
* Docente.
* Nota final.
* Estado de la asignatura.
* Periodo académico.
* Número de créditos.
* Cantidad de estudiantes matriculados.

Estos datos podrían encontrarse en el sistema de información académica utilizado por la universidad y posteriormente ser exportados a archivos Excel o CSV para realizar el análisis.

### Posible flujo

```text
Sistema académico
       │
       ▼
 Datos académicos
       │
       ▼
 Excel / CSV
       │
       ▼
    Power BI
       │
       ▼
 Dashboard académico
```
