# Semana 7 - Power Query

## Descripción

Se realizó una conexión de Power BI con tres archivos CSV que contienen información de ventas mensuales.

Los archivos utilizados fueron:

- Ventas_Enero.csv
- Ventas_Febrero.csv
- Ventas_Marzo.csv

Todos mantienen la misma estructura de columnas.

## Proceso realizado

Los archivos fueron conectados mediante:

Power BI → Obtener datos → Carpeta

Posteriormente se utilizó:

Combinar y transformar datos

Power Query permitió unir todos los archivos en una sola tabla.

## Actualización de nuevos archivos

Cuando exista un nuevo archivo del siguiente mes, por ejemplo:

Ventas_Abril.csv

solo debe agregarse dentro de la misma carpeta.

Al actualizar Power BI, Power Query detectará el archivo nuevo y aplicará automáticamente los mismos pasos de transformación sin tener que repetir el proceso.
